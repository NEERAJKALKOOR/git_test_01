# Student Grade Calculator

A simple Python project that calculates a student's average marks
and determines the corresponding grade.

## Features

- Accepts student name
- Accepts marks for three subjects
- Calculates average marks
- Determines grade
- Displays the final result

## Technologies

- Python 3
- Git

## How to Run

```bash
python app.py
